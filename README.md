# OT Calculator

Android Jetpack Compose app for tracking OT and Stayback hours.

## Main features
- OT or Stayback entry by date
- Automatic amount calculation
- AED 50 daily allowance for every OT/Stayback day
- Monthly totals for OT, Stayback and allowance
- Salary, Ramadan, PH, Split and WPC payments before Grand Total
- Month-by-month history
- Editable rates and defaults in Settings
- Data saved locally on the phone

## Default values
- OT rate: AED 17.64/hour
- Stayback rate: AED 14.70/hour
- Daily allowance: AED 50.00
- Salary: AED 2,446.00

Open the project in Android Studio, allow Gradle sync, then Run or Build APK.
